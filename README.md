# NeuroShield
Target Users: 
- Banks & Financial Institutions – Detect fraudulent payments and transactions.
- E-commerce & Payment Gateways – Ensure secure transactions in online purchases.
- Individual Users – Get fraud alerts on personal transactions.

Core Functionalities
- Fraud Risk Scoring – Assign fraud probability to transactions.
- Real-Time Detection – Process transactions instantly via FastAPI.
- Machine Learning AI Models – Use trained fraud detection algorithms.
- User Dashboard – Monitor transactions interactively with Streamlit.
- Automated Fraud Alerts – Notify users of high-risk activity.

- Technical Requirements
- FastAPI Backend – Handle fraud detection requests.
- Machine Learning Model – Classify transactions as fraudulent or safe.
- Streamlit Frontend – Provide a dashboard for fraud analysis.
